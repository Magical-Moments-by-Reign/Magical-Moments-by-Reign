# Luxury Services — photo upload guide

Drop your photos at the exact paths below and each tile becomes photographic
automatically. Until a file exists, an elegant warm-gradient fallback shows —
the page is never broken. Filenames must match exactly (lowercase, `.jpg`).

**Format:** JPG (or swap the extension in code if you prefer WebP). Landscape.
Keep each file reasonably sized (< ~400 KB) so pages stay fast.
